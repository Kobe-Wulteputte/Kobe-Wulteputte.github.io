Bank Sync

What is it?

I have always liked keeping track of my expenses. What started out a simple Excel file to keep track of how much i spend on food and drinks has evolved into a full blown money management system. The system makes use of a number of tools to both retreive the data and draw conclusions from it. The goal is to be able to see where my money goes and to be able to make better decisions on how to spend it. All this should be done automatically and without any effort on my part.

How does it work?

The system is based on a number of tools that work together to achieve the goal. The tools are:

  • Nordigen, to retreive bank transactions from multiple sources
  • An Azure funtion to call the Nordigen API, process and label the data and finally write the changes to a file
  • A second Azure function to periodically read all past transactions and extract information for labeling new data
  • A Power Bi report to visualise the data
