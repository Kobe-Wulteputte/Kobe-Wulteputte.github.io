# Digitizing the Inspection Certificate

I executed this project for multiple Belgian inspection companies. All these companies internally work with the same software package for recording inspections and drawing up the inspection certificate.

To keep the inspection certificate up to date, the inspection companies requested a portal where anyone who has had an inspection performed can retrieve their results digitally. It was important that it be simple for all kinds of users to request the data.

So a simple web application was developed that can be consulted via a QR code on the inspection certificate. An integration with "Mijn Burgerprofiel" was also provided to retrieve the data without having to have the certificate in hand.

## My Role in the Team

I executed this project with 2 fellow developers and 1 Project manager. My tasks were first to create a functional and technical analysis. This in consultation with the client. Subsequently, I took on the role of technical lead during the development process. My tasks as lead included guiding integrations with the inspection certificate software package and setting up the cloud environment and pipelines.

## Peppol

In a later phase of the project, it was also decided to extend this portal with a Peppol integration. This allows customers of the inspection companies to independently request and send their invoices via Peppol. This reduces the workload at the companies and ensures that everyone gets their inspections correctly and smoothly into their accounting.

## What Was Important

In this project we collaborated with multiple inspection companies, multiple IT partners of these companies, and even technical departments of the government to retrieve vehicle data and send it to "Mijn Burgerprofiel".
Due to the large number of parties involved, clear communication was essential. Each party had to be aware of the project's goals and know what to do both functionally and technically. This was consequently the most challenging aspect of the project.
