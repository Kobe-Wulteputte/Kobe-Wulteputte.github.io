# Custom ERP for Terminal in the Port of Antwerp

## Background and Context

I contributed to the development of a fully customized ERP system for a terminal company operating in the Port of Antwerp. The existing software package no longer met operational requirements and lacked extensibility, while the organization increasingly needed specialized processes and integrations. For these reasons, a deliberate choice was made to develop custom software.

## Complex Integrations and High Availability

A major challenge within this project was the large number of custom integrations. The ERP system communicates with external customers via EDI, as well as with various internal systems. Additionally, continuous availability was critical. Since internet connectivity is not always guaranteed, the system is hosted on-premises and remains fully operational without external connectivity.

## My Role and Growth Within the Project

I started this project as a junior developer, where my initial focus was on following analyses and developing master data management. Over time, I took on increasing responsibility. I expanded multiple modules in scope and took ownership of a large portion of external EDI integrations. Additionally, I contributed to keeping the application performant and stable. The project requires broad technical knowledge, ranging from database and backend to frontend, and I work here as a full-stack developer alongside a few other developers.

## Architecture and Technology

Architecturally, the application has evolved over time toward a more microservice-oriented structure. This allowed components to be developed more independently and to scale better as complexity increased. The system is built around a .NET backend API with SQL Server as the database and an Aurelia.js frontend application. These technologies align closely with Orbid's expertise, which also handles complete hosting and technical management.

## Expansion Toward Operational Software

Alongside the ERP system, I am currently working with this client on additional software deployed directly at the terminal to manage operational workflows. Examples include self check-in solutions and tablet applications for field staff. According to the client, this is a unique system that no other terminal in the port currently possesses. Because everything is fully customized, optimizations are possible that perfectly align with their operations, resulting in a highly efficient and user-friendly solution.

## Conclusion

This project illustrates how custom software, combined with close collaboration and technical expertise, can grow into a critical component within a complex operational environment. For me personally, it represented a steep learning curve and an evolution from executing tasks to taking on substantive responsibility within a large-scale, business-critical system.
